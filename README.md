# ContainerBodega releases

Signed, notarized builds of **ContainerBodega**, a native macOS app for Apple's
[`container`](https://github.com/apple/container) CLI. This repository holds
release downloads only; there is no source code here.

## Install

With Homebrew:

```bash
brew install --cask intrusive-memory/tap/containerbodega
```

Or download `ContainerBodega.dmg` from the [latest release](../../releases/latest),
open it and drag **ContainerBodega** to Applications.

## Requirements

- macOS 26 (Tahoe) or later, Apple silicon
- Apple's [`container`](https://github.com/apple/container/releases) CLI

Website: <https://container-bodega.app>

Releases here are published automatically. Please don't open pull requests.
